# Security

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/atmin-ca/review/security/advisories/new).
Private reporting is enabled for this repository.

Include reproduction steps, affected versions, and the expected security boundary.
Do not include credentials or customer source in public issues. Share the minimum
information needed to reproduce a problem privately.

This experimental alpha investigates source only. Its worker is not a sandbox for
running untrusted repository scripts or an isolation boundary between tenants.
